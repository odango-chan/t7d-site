# Public Site Boundary

`t7d-site` is the public presentation repository for **東方七日祭 ～ Seven Days of Leisure**.

## Source of truth

Production source lives in:

- `odango-chan/touhou-seven-days`

This public repository contains only approved release material.

## May be published here

- released novel prose;
- accepted manga pages / web-optimized images;
- accepted character portraits;
- public game screenshots / trailers;
- public release notes;
- game download / store links;
- fan-work notice.

## Must not be copied here

- prompts;
- internal production documents;
- Story / Character draft discussions;
- gap ledgers;
- QA history;
- issue-only planning;
- unapproved art;
- production-only high-resolution assets;
- secrets / signing material.

## Export rule

Each imported content item should retain machine-readable upstream provenance:

- source repository;
- source path;
- source commit / blob SHA where practical.

The public copy is a release artifact. Editing story prose directly in this repository is discouraged; prose fixes should normally land upstream first, then be re-exported.

## Site scope

This repository is intentionally broader than the novel:

- Novel
- Manga
- Characters
- Game
- News / release information
- About / fan-work notice

The public site is the audience-facing surface for the whole project.
